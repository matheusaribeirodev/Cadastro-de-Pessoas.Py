# Cadastro-de-Pessoas.Py
📋 Sistema de Cadastro de Pessoas

Um sistema simples desenvolvido em Python para realizar o cadastro e listagem de pessoas utilizando arquivos .txt para armazenamento de dados. O projeto foi criado com foco em praticar lógica de programação, manipulação de arquivos e estruturas de repetição.

🚀 Funcionalidades

Cadastro de pessoas
Armazenamento em arquivo .txt
Listagem de usuários cadastrados
Menu interativo no terminal
Sistema simples e intuitivo
